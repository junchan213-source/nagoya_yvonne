新手超簡單！4 步驟免費放到 GitHub 變成手機 APP

步驟 1：下載 index.html

先在這個畫面把行程改好，接著點擊上方金色的「點此直接下載 index.html 網頁檔」按鈕，檔案就會存到您的電腦或手機。

步驟 2：在 GitHub 建立專案

登入 github.com，點右上角 「+」號 ➔ New repository。在 Repository name 輸入 nagoya-trip，選擇 Public，再點最下方綠色 Create repository。

步驟 3：上傳 index.html

在新建好的頁面中，點擊藍字 「uploading an existing file」，把剛剛下載的 index.html 拖曳進去，再點下方綠色按鈕 Commit changes。

步驟 4：開啟 GitHub Pages 網址

點專案上方的 ⚙️ Settings ➔ 左側選單點 Pages ➔ 在 Branch 下拉選單把 None 改為 main 並按 Save。等 1 分鐘重新整理，上方就會出現您的專屬網址！

📱 進階秘訣：把網址變成手機桌面真 APP 圖示！

用手機打開您的 GitHub Pages 網址後：
• iPhone (Safari)：點擊底部中間的「分享 」按鈕 ➔ 往下滑點選「加入主畫面」。
• Android (Chrome)：點擊右上角「⋮」選單 ➔ 點選「加到主畫面」或「安裝應用程式」。
